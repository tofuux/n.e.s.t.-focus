

# 🧠 N.E.S.T — Neuro Emotional Support & Tracking
A real-time AI assistant that enhances **focus, communication, and execution** through intelligent meeting support, emotional awareness, and cognitive insights.

---

## 🚀 Overview

**N.E.S.T** is an AI-powered productivity system that acts as your:

* 🧠 Cognitive support system
* 💬 Meeting copilot
* 📋 Task execution engine
* 📊 Personal productivity analyst

It reduces overwhelm, improves communication, and ensures tasks actually get completed — not just planned.

---

## ✨ Key Features

### 🧠 Cognitive Dashboard

* Mood-based check-ins that adapt system behavior
* Dynamic **Focus Score** based on engagement and activity
* Centralized view of tasks, meetings, and priorities
* AI-driven “What should I focus on next?” recommendations

---

### 🎙️ Live Meeting Copilot

* Real-time **Speak / Wait cues** for optimal participation
* Tone analysis to detect:

  * Harsh communication
  * Unclear phrasing
  * Ineffective responses
* AI message simplifier for clear communication
* Auto-generates:

  * Meeting summaries
  * Key decisions
  * Action items

---

### 😌 Emotion & Stress Detection

* Uses camera input (with user permission) to detect:

  * Stress levels
  * Emotional state
  * Signs of overwhelm
* Adapts system behavior in real-time:

  * Suggests breaks
  * Simplifies tasks
  * Adjusts meeting guidance
* Provides gentle nudges like:

  * “You seem overwhelmed — let’s take this step by step”

---

### 📄 Context-Aware Document Intelligence 

* Upload documents before or during meetings:

  * PDFs
  * Notes
  * Reports
  * Docs
* AI uses these as **context during discussions**
* Enables:

  * Smart answers grounded in your documents
  * Context-aware response suggestions
  * Better decision-making in meetings

---

### ✅ Intelligent Task Execution

* Smart task manager with **priority-based organization**
* AI breaks tasks into **micro-steps**
* Detects overload and suggests manageable next actions
* Tracks progress from:

  * Planning → Execution → Completion

---

### 📊 Memory & Insights Engine

* Persistent, searchable memory of:

  * Meetings
  * Tasks
  * Conversations
  * Documents
* Context-aware recall of past discussions
* Tracks productivity trends and behavior patterns
* Generates personalized insights to improve performance

---

## ⚡ How It Works

### 🔹 During Meetings

### 🔹 After Meetings

## 🏗️ Tech Stack (Suggested)

 Locally built AI support
 Speech & Emotion : Whisper + OpenCV + CNN
 Backend & Frontend :FastAPI/Node + React
 Database: PostgreSQL 
                     


## 🧩 Architecture Overview

```
User Input (Voice / Text / Camera / Documents)
            ↓
Multi-Modal AI Layer
(Context + Emotion + Tone + Intent)
            ↓
Decision Engine
(Tasks / Suggestions / Insights)
            ↓
Memory Layer
(Meetings + Tasks + Docs + Behavior)
            ↓
Frontend Dashboard
```
